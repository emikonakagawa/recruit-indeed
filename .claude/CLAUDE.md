# CLAUDE.md

このファイルは、Claude がこのワークスペースで作業する際のガイドです。

## ワークスペース概要

このフォルダは、**Indeed に掲載する求人情報を xlsx 形式で作成する業務**の作業フォルダです。コードリポジトリではなく、ソースコード・ビルドシステム・git はありません。生成した xlsx は、そのまま Indeed の管理画面にアップロードします。

対象は次の **3 社**です。掲載内容は会社ごとに異なるため、ファイル・内容を混在させないでください。

- **iRup**（アイラップ）
- **UPBUILD**（アップビルド）
- **Xedge**（エッジ）

> 媒体は当面 **Indeed のみ**を自動化対象とします（engage は対象外）。

## 設計の考え方（3 層分離）

値の「出どころ」を 3 つに分けて管理します。これにより、会社・勤務地・職種ごとの差分が一箇所に集約され、確認・修正がしやすくなります。

| 層 | 置き場所 | 持つもの |
| --- | --- | --- |
| ① 職種テンプレート | `テンプレート/テンプレート（職種）.xlsx` | 列レイアウト＋職種共通の固定値＋プレースホルダ注釈 |
| ② 会社別設定 | `.claude/companies/<会社>/設定.md` | 会社固有の固定値・勤務地候補・運用ルール・訴求素材 |
| ③ 共通スキル/手順/ブリーフ | `.claude/skills/draft-jobs/`・`.claude/求人作成手順.md`・`.claude/briefs/` | 生成ロジック・ワークフロー・職種別の生成ブリーフ（**全社共通**） |

テンプレート内のセルは注釈タグで出どころを示します（→ 詳細は `.claude/列定義.md`）。

- `【AI生成】` … スキルが毎回生成する変動値
- `【会社毎】` … 会社別設定（`companies/<会社>/設定.md`）から転記
- `【勤務地毎】` … 勤務地に応じて決まる値
- `【会社・勤務地毎】` … 会社×勤務地で決まる値
- `【内容固定／表現はAI生成】` … 内容は固定だが言い回しは毎回変える
- 注釈なし … そのまま使う固定値

**優先順位**: 職種テンプレートの固定値が既定。同じ列を `companies/<会社>/設定.md` が指定している場合は **会社別設定が優先（上書き）**。

## 会社 × 職種 × 件数の対応

| 会社 | 職種 | 件数の数え方 | 勤務地 |
| --- | --- | --- | --- |
| iRup | エンジニア | 件数＝エンジニア求人の本数 | 東京（池袋/品川/渋谷/新宿ハブ）・愛知（名古屋） |
| UPBUILD | エンジニア | 件数＝エンジニア求人の本数 | 東京・愛知（名古屋） |
| Xedge | 5 職種（Webデザイン/マーケティング/動画編集/出版/エンジニア） | **1 セット＝5 職種各 1 件**。件数＝セット数（2 セット＝5 職種×2＝10 件） | 東京・愛知（名古屋） |

## 作業の入口

求人作成は **`draft-jobs` スキル**（または `/求人作成` コマンド）で開始します。スキルが最初に「会社」と「件数」を尋ね、`companies/<会社>/設定.md`・該当職種の共通ブリーフ `.claude/briefs/<職種>.md`・職種テンプレートを読み込んで進めます。ワークフローの詳細は `.claude/求人作成手順.md` を参照してください。

## 注意事項

- 3 社は **別ワークストリーム**として扱い、ファイル・内容を混在させない。
- `テンプレート/` 配下のマスターは、明示的に指示されない限り **直接編集しない**。必ずコピーしてから記入する。
- 成果物 xlsx は `<会社>/<会社>_YYYYMMDD.xlsx` に保存する。
- やり取りは **日本語**で行う。
- iRup の会社固有値（社名・連絡先・画像 ID 等）は未確定のため、`companies/iRup/設定.md` に **TODO** として枠だけ用意してある。確定し次第埋めること。
- **本文中の会社名は `(株)iRup` で統一**: UPBUILD・Xedge は iRup のグループ会社のため、AT/AU/AV/E など本文中で会社名を呼ぶときは、どの会社の求人でも `(株)iRup`（短く `iRup`）に統一する。B 列（Indeed の正式社名フィールド）は各社の正式表記を維持。詳細は `.claude/本文スタイル.md` を参照。
- **C 列「職種名」は「【キャッチコピー】普通の文章」一文スタイル**: `◆` や `／` `｜` でフレーズを区切らず、`【】` の後ろは自然な一文にする。会社・職種問わず統一。詳細は `.claude/列定義.md` の C 列セクション参照。
- **エンジニアの C 列は固定書式**: `【未経験可】フルリモート〇〇エンジニア`（〇〇 は `.claude/エンジニア専門領域.md` の一覧から 1 つだけ選ぶ）。並べ替え・省略・追加訴求の混入は禁止。Indeed の審査エラー（「職種名が不明確」「職種名以外の情報が含まれている」）を回避するためのルール。iRup・UPBUILD・Xedge 全社のエンジニア求人で統一。
- **給与・勤務形態の固定ルール（会社問わず）**: N（最高額）はエンジニアのみ固定（東京=`600000` / 名古屋=`500000`）、その他は空欄。W（勤務形態）は全社・全職種で `固定時間制、フレックスタイム制度` 固定。BA（給与補足）冒頭の月給レンジ表記は東京=25万円〜・名古屋=23万円〜、エンジニアのみ最高額あり（東京60万 / 名古屋50万）。詳細は `.claude/列定義.md` の給与関連セクション参照。
- **Indeed 入力許容値（AD/BE/BF/BG）**: AD は `か月`（`ヶ月` は弾かれる）。BE/BF/BG タグは Indeed 許容リスト（`在宅OK`/`昇給・昇格あり`/`交通費支給`/`フルリモート` 等）からのみ。旧テンプレに残る `在宅あり`/`昇給あり` は **生成時に置換**。詳細は `.claude/列定義.md` の AD と BE/BF/BG セクション参照。
