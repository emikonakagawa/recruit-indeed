# 求人ドラフト作成（共通スキル）

iRup・UPBUILD・Xedge の Indeed 求人を新規作成する共通スキル。このファイルはワークフローのみを担当し、列ルール・本文スタイル・C 列固定書式は SSoT ファイルから読む。

## 関連ドキュメント（毎回読む）

| 用途 | ファイル |
| --- | --- |
| 全体俯瞰・地図 | `.claude/CLAUDE.md` |
| 列の分類・入力規則・全固定ルール（M/N/W/BA/AD/タグ/H/BR/C 列スタイル） | `.claude/列定義.md` |
| 本文スタイル（AT/AU/AV の構造・文体・◆見出し） + 本文中の社名表記（各社の自社名） | `.claude/本文スタイル.md` |
| エンジニア C 列固定書式・〇〇一覧・技術スタック早見表 | `.claude/エンジニア専門領域.md` |
| 会社固有の固定値・勤務地候補・運用ルール・訴求素材 | `.claude/companies/<会社>/設定.md` |
| 職種別「何を伝えるか」（テーマ・素材） | `.claude/briefs/<職種>.md` |
| 職種テンプレート（**直接編集禁止**） | `テンプレート/テンプレート（職種）.xlsx` |

## 値の出どころ（3 層 + 全社固定ルール）

テンプレートのセルは注釈タグで出どころを示す（タグの意味は `.claude/列定義.md` の「注釈タグの意味」セクション参照）。

- `【AI生成】` … このスキルが briefs に沿って生成（C/E/AT/AU/AV など）
- `【会社毎】` … `設定.md` から転記
- `【勤務地毎】` / `【会社・勤務地毎】` … `設定.md` の勤務地候補から決定
- `【内容固定／表現はAI生成】` … 内容固定・言い回しは毎回変える
- 注釈なし … テンプレの固定値

**全社共通の固定ルール**（テンプレ既定や `設定.md` の指定よりこちらが優先）は **`.claude/列定義.md`** が SSoT：
M / N / W / BA 冒頭 / AD / BE・BF・BG タグ / H / BR ／ C 列スタイル ／ F 列 7 桁文字列。

## ワークフロー

### ステップ 0: 会社と件数を確認（最初に必ず）

1. **会社** を確認（iRup / UPBUILD / Xedge）。
2. **件数** を確認。
   - iRup / UPBUILD: エンジニア求人の本数（例: 10）。
   - Xedge: **セット数**。1 セット＝4 職種（Web/マーケ/動画/出版）各 1 件。2 セット＝8 件。（Xedge はエンジニア求人を作らない）
3. 必要なら **勤務地配分**（東京・名古屋の内訳）を確認。`設定.md` に既定配分があれば提案する。

引数（コマンド経由）で会社・件数が渡っていれば、それを使い、不足分だけ聞く。

### ステップ 1: 読み込み

会社が決まったら、上記「関連ドキュメント」を読み込む。Xedge は 4 職種（Web/マーケ/動画/出版）すべての `.claude/briefs/` を読む（エンジニアは読まない）。

### ステップ 2: 生成

共通ブリーフ `.claude/briefs/<職種>.md` に沿って `【AI生成】` 項目を件数分作成する（会社固有の数字・強み・共通文素材は `設定.md` から補う）。

- 主な生成対象: C / E / AT / AU / AV、職種テンプレで `【AI生成】` 指定の AX/BA/BC 等
- AT/AU/AV の構造・文体は **`.claude/本文スタイル.md`** に従う
- エンジニアの C 列は **`.claude/エンジニア専門領域.md`** の固定書式・〇〇一覧から
- 文字数・記法・空欄ルール・F 列 7 桁文字列・H 列固定値などは **`.claude/列定義.md`** に従う

### ステップ 3: xlsx 直接出力（md ドラフトは作らない）

中間の確認用 md は **作らない**。生成した内容は職種テンプレをコピーした xlsx に直接書き込む。**全社（iRup・UPBUILD・Xedge）共通でこの直接 Excel 出力フロー**。

- **コピー元**: `テンプレート/テンプレート（職種）.xlsx`（**直接編集禁止**）
- **出力先**: `<会社>/<会社>_YYYYMMDD.xlsx`（同名があれば連番）
- **会社ごとに 1 ファイル**。`求人入力シート` の 2 行目以降に 1 求人＝1 行で記入。
- Xedge は 4 職種（×セット数）を 1 ファイルに並べ、**行ごとに対応する職種テンプレ＋ブリーフ**の固定値・生成内容を適用する。
- 各行で埋めるのは「AI生成項目＋会社毎＋勤務地毎」。注釈なしの固定値はテンプレの値をそのまま使う。`設定.md` に上書き指定がある列はそちらを優先。さらに **`.claude/列定義.md` の全社共通固定ルール（M/N/W/BA/AD/タグ）でテンプレ既定・設定.md を上書きする**。
- **テンプレ注釈の残り掃除（必須）**: テンプレ 2 行目には `【会社毎】…` `【勤務地毎】…` 等のプレースホルダ注釈がセルに入っている。書き込まない列（例: **BR2・I2**）にこの注釈が残ると一括アップロード検証で弾かれる（BR は 30 字超エラー）。**xlsx 保存前に、データ行(2行目以降)の全セルを走査し、`【…】` 注釈タグが残っているセルを `None` で空欄化する**。
- **D 列（職業カテゴリー）は Indeed 有効リーフのみ**。`エンジニア専門領域.md` の「D 列『職業カテゴリー』の有効値」一覧から選ぶ（`インフラエンジニア`/`QAエンジニア`/`システムエンジニア`(親) 等は弾かれる）。

実装例（Python / openpyxl）:

```python
import openpyxl, shutil
src = "テンプレート/テンプレート（エンジニア）.xlsx"   # 職種で切り替え
out = "UPBUILD/UPBUILD_20260524.xlsx"
shutil.copy(src, out)
wb = openpyxl.load_workbook(out)
ws = wb["求人入力シート"]
# rows = [ {列: 値, ...}, ... ]  # 会社毎＋勤務地毎＋AI生成をマージ済みの dict
for i, row in enumerate(rows):
    r = i + 2
    for col_letter, val in row.items():
        ws[f"{col_letter}{r}"] = val
# F 列は必ず文字列
for i in range(len(rows)):
    c = ws.cell(i+2, 6)
    if c.value is not None:
        c.value = str(c.value).split(".")[0]
wb.save(out)
```

**ビルドスクリプトは使い捨て**。`.claude/skills/draft-jobs/` 配下に保存しない。`python3 -c "..."` か Bash ヒアドキュメントで実行するか、どうしても一時ファイルが必要な場合は `/tmp/build_<会社>_<日付>.py` に置き、完了後に削除する。

### ステップ 4: 完了報告（＋スマホ通知）

出力ファイルパスと各行のサマリ（C/職種/F・G）をチャットで報告する（**本文の全文はチャットに貼らない**）。「xlsx 出力完了。内容を確認し、修正があれば指示してください。Indeed へのアップロードはユーザー側で実施してください」と伝える。

xlsx 出力が完了したら、**`PushNotification` ツールでスマホに完了通知を送る**（Remote Control 接続時のみ届く。未接続なら送信されないだけで問題なし）。メッセージは 1 行・200 字以内で、会社名・件数・ファイル名を入れる。例: `UPBUILD エンジニア5本の求人xlsx出力完了：UPBUILD_20260531.xlsx`。修正ループ（ステップ 5）の途中では送らず、**最終的に xlsx が確定したタイミングで 1 回**送る。

### ステップ 5: 修正ループ

修正指示があれば、**生成済みの xlsx を直接編集**して該当セルだけ書き換え（テンプレ原本ではなく出力ファイルを編集）、編集箇所のサマリのみ提示する。OK が出るまで繰り返す。

- [ ] ステップ 0 で **会社と件数** を確認した

- [ ] テンプレを直接編集していない／F 列が文字列 7 桁／`列定義.md` の固定ルールでテンプレ既定・設定値を上書きした
