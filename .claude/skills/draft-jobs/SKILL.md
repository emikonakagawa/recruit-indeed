# 求人ドラフト作成（共通スキル）

iRup・UPBUILD・Xedge の Indeed 求人を新規作成する共通スキル。会社別の差分は `companies/<会社>/` の設定とブリーフに集約されているので、このスキルはワークフローと共通ルールを担う。

## 関連ドキュメント（毎回読む）

- 全体ルール・フォルダ地図: `.claude/CLAUDE.md`
- 全体ワークフロー: `.claude/求人作成手順.md`
- 列の分類・入力規則: `.claude/列定義.md`
- **本文スタイル（AT/AU/AV の構造・文体・◆見出しルール）: `.claude/本文スタイル.md`**
- 会社固有の固定値・勤務地候補・運用ルール・訴求素材: `companies/<会社>/設定.md`
- 各職種の生成ブリーフ（**全社共通**）: `.claude/briefs/<職種>.md`
- 職種テンプレート（直接編集禁止）: `テンプレート/テンプレート（職種）.xlsx`

## 値の出どころ（3 層）

テンプレートのセルは注釈タグで出どころを示す。

- `【AI生成】` … このスキルが briefs に沿って生成（C/E/AT/AU/AV など）
- `【会社毎】` … `設定.md` から転記（B 社名/BD 画像/BM メール/BN 電話/BH 採用数/BJ 応募者情報 など）。**BR ユーザー指定IDは全社・全職種で空欄**
- `【勤務地毎】` … `設定.md` の勤務地候補から決定（F/G）。**H 列は会社・職種を問わず固定**（名古屋=`1-7-25` / 東京=空欄）、I 列は空欄
- `【会社・勤務地毎】` … 会社×勤務地で決定。**ただし以下は会社問わず固定ルール**（`設定.md` よりこちらが優先）:
  - **M**（最低額）: 東京=`250000` / 名古屋=`230000`
  - **N**（最高額）: エンジニアのみ固定（東京=`600000` / 名古屋=`500000`）、エンジニア以外は空欄
  - **W**（勤務形態）: 全社・全職種で固定 `固定時間制、フレックスタイム制度`
  - **BA**（給与補足）冒頭: エンジニア東京=`月給：25万円〜60万円＋各種手当` / 名古屋=`月給：23万円〜50万円＋各種手当`、エンジニア以外 東京=`月給：25万円〜　＋各種手当` / 名古屋=`月給：23万円〜　＋各種手当`（モデル年収等の補足は職種別に追加）
- `【内容固定／表現はAI生成】` … 内容固定・言い回しは毎回変える（BB など）
- 注釈なし … 固定値（A/J/K/L/P/X/Z/AB-AE/BI など）

**優先順位**: テンプレの固定値が既定。`設定.md` に同じ列の指定があれば **会社別設定が優先（上書き）**。

## ワークフロー

### ステップ 0: 会社と件数を確認（最初に必ず）

1. **会社** を確認（iRup / UPBUILD / Xedge）。
2. **件数** を確認。
   - iRup / UPBUILD: エンジニア求人の本数（例: 10）。
   - Xedge: **セット数**。1 セット＝5 職種（Web/マーケ/動画/出版/エンジニア）各 1 件。2 セット＝10 件。
3. 必要なら **勤務地配分**（東京・名古屋の内訳）を確認。`設定.md` に既定配分があれば提案する。

引数（コマンド経由）で会社・件数が渡っていれば、それを使い、不足分だけ聞く。

### ステップ 1: 読み込み

会社が決まったら、上記「関連ドキュメント」を読み込む。Xedge は 5 職種すべての `.claude/briefs/` を読む。

### ステップ 2: 生成

共通ブリーフ `.claude/briefs/<職種>.md` に沿って、`【AI生成】` 項目を件数分作成する（会社固有の数字・強み・共通文素材は `設定.md` から補う）。

- C 職種名（必須・30 字前後）
- E 求人キャッチコピー（任意・256 字以内・**改行不可**）
- AT 仕事内容（必須・30 字以上。記法: `*太字*` / `_斜体_` / `- 箇条書き` / 段落は空行）
- AU アピールポイント（必須）
- AV 求める人材（任意）
- 職種テンプレで `【AI生成】` になっている AX/BA/BC 等もブリーフに沿って生成（テンプレに固定共通文が入っている場合はそれを既定として尊重）

**AT / AU / AV の本文は必ず `.claude/本文スタイル.md` のスタイル（オープニング → 共感 → ◆ ブロック → クロージング、見出しは `◆ 【キーワード】タイトル` 形式）に沿って生成する**。職種別の「何を伝えるか」は briefs、文体・構造は本文スタイル.md が担う。

`【勤務地毎】`（F/G）は `設定.md` の勤務地候補から選定。F は **半角 7 桁文字列**。H 列は会社・職種を問わず固定で、名古屋=`1-7-25` / 東京=空欄。I 列は空欄。

### ステップ 3: md 出力（チャットではなくファイル）

- **出力先**: `<会社>/drafts/YYYYMMDD.md`（日付は実行日。同名があれば `YYYYMMDD-2.md` と連番）
- `<会社>/drafts/` が無ければ作成。
- チャットには全文を貼らない。ファイルパスと、各行の C 職種名・職種・F/G 勤務地のみを短くサマリ表示。
- 「ファイル `<会社>/drafts/YYYYMMDD.md` を確認してください。この内容で良いですか？」と尋ねる。

### ステップ 4: 修正ループ

修正指示があれば該当箇所だけ md を編集し、編集箇所のサマリのみ提示。OK が出るまで繰り返す。

### ステップ 5: xlsx 出力（OK 後は必ず実施）

- **コピー元**: `テンプレート/テンプレート（職種）.xlsx`（**直接編集禁止**）
- **出力先**: `<会社>/<会社>_YYYYMMDD.xlsx`（同名があれば連番）
- **会社ごとに 1 ファイル**。`求人入力シート` の 2 行目以降に 1 求人＝1 行で記入。
- Xedge は 5 職種（×セット数）を 1 ファイルに並べ、**行ごとに対応する職種テンプレ＋ブリーフ**の固定値・生成内容を適用する。
- 各行で埋めるのは「AI生成項目＋会社毎＋勤務地毎」。注釈なしの固定値はテンプレの値をそのまま使う。`設定.md` に上書き指定がある列はそちらを優先。
- F 列は **文字列 7 桁**（`1500043.0` のような float 化禁止）。

実装例（Python / openpyxl）:

```python
import openpyxl, shutil
src = "テンプレート/テンプレート（エンジニア）.xlsx"   # 職種で切り替え
out = "UPBUILD/UPBUILD_20260524.xlsx"
shutil.copy(src, out)
wb = openpyxl.load_workbook(out)
ws = wb["求人入力シート"]
# rows = [ {列: 値, ...}, ... ]  # 会社毎＋勤務地毎＋AI生成をマージ済みの dict
for i, row in enumerate(rows):
    r = i + 2
    for col_letter, val in row.items():
        ws[f"{col_letter}{r}"] = val
# F 列は必ず文字列
for i in range(len(rows)):
    c = ws.cell(i+2, 6)
    if c.value is not None:
        c.value = str(c.value).split(".")[0]
wb.save(out)
```

**ビルドスクリプトは使い捨て**。`.claude/skills/draft-jobs/` 配下に保存しない。`python3 -c "..."` か Bash ヒアドキュメントで実行するか、どうしても一時ファイルが必要な場合は `/tmp/build_<会社>_<日付>.py` に置き、完了後に削除する。

### ステップ 6: 完了報告

出力ファイルパスと各行のサマリ（C/職種/F・G）をチャットで報告し、「xlsx 出力完了。Indeed へのアップロードはユーザー側で実施してください」と伝える。
