# 職種ブリーフ（共通）/ 出版

**全社共通**の生成ブリーフ（クリエイティブ職・未経験育成のグラフィック・DTP・出版枠）。
会社固有の固定値・給与レンジ・福利厚生・勤務地は `companies/<会社>/設定.md` を参照。列規則は `.claude/列定義.md`。

**本文（AT/AU/AV）の構造・文体・見出し書式は `.claude/本文スタイル.md` に従う**（オープニング → 共感 → `◆ 【キーワード】タイトル` ブロック → クロージング）。このブリーフは「何を伝えるか（テーマ・素材）」を担う。

## ターゲット
モノづくりが好きな層・形に残る仕事がしたい層。

## C 職種名（書式は「【キャッチコピー】普通の文章」一文スタイル）

`【】` 内に短いキャッチコピー、`】` の後は自然な一文。**◆ や ／ ｜ などで区切らない**（書式詳細は `.claude/列定義.md` の C 列セクション参照）。

例（コピーせずトーン・フックを参考に）:
- `【未経験OK】書籍からグッズまで手がける出版デザイナー`
- `【未経験OK】マニュアル完備で安心デビューできる出版デザイナー`

## AT 仕事内容の核
- 書籍・雑誌・商品パッケージ・イベント用パネル・グッズのデザイン・制作
- 単なる制作スタッフでなく、企業のブランディング（価値づくり）という上流工程から関わる
- クリエイターとしてのやりがい抜群

## AU アピールポイントの核
- 未経験でも安心の体制: DTP の基礎から印刷の仕組みまで詳細マニュアル完備、先輩が隣で指導
- エンタメ好き大歓迎: アニメやライブ会場を彩るパネル、限定グッズなどの制作案件多数
- キャリアの広がり: 紙媒体だけでなく Web や動画の経験も積めるハイブリッドデザイナーへ

## AV 求める人材の核
未経験・第二新卒・若手歓迎。ものづくり・本・パッケージ・エンタメが好きな方歓迎。

## トーン
熱量高めの語りかけ調。安心感（研修・マニュアル完備）。数字は会社設定・テンプレ既定と整合。記号可、**絵文字なし**。
