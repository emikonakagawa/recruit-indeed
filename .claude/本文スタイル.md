# 本文スタイル（AT 仕事内容 / AU アピールポイント / AV 求める人材）

iRup・UPBUILD・Xedge の **全社・全職種で共通の本文スタイル**。
AT（仕事内容）／AU（アピールポイント）／AV（求める人材）の 3 つは、このスタイルに沿って生成する。

職種固有の「何を伝えるか（テーマ・コアメッセージ）」は各 `.claude/briefs/<職種>.md` を参照。
このファイルは「どう書くか（構造・文体）」を担う。

---

## 全体の構造（AT / AU 共通）

> **AV（求める人材）は例外**：この ◆ ブロック構造ではなく、`■` 見出し＋`・` 箇条書きのテンプレート形式で書く（詳細は下の「項目別の使い分け → AV 求める人材」を参照）。

1. **オープニング**（2〜3行）
   - 強いメッセージで読者の意欲を引き出す
   - 「未経験からプロへ。あなたのキャリアを100%の環境でバックアップします。」のような言い切り
2. **共感パート**（任意・AT/AV で有効）
   - 不安や悩みに寄り添う問いかけ
   - 「『〜だろうか』そんな不安を抱える必要はありません。」のように受け止める
3. **本文の柱**（◆ ブロックの繰り返し）
   - `◆ 【キーワード】キャッチーなタイトル一行` の形で 3〜5 ブロック
   - 各ブロックは 2〜4 行の説明＋必要に応じて `・` で要素列挙
4. **クロージング**（任意・AT で有効）
   - 熱量のある締めで応募意欲を後押し
   - 「あなたの『本気』を、私たちは全力で受け止めます。」のような呼びかけ

## 見出しの書式: `◆ 【キーワード】タイトル`

- 先頭は **半角の `◆` ＋半角スペース**
- `【】` の中はベネフィットを示す **短いキーワード**（期間・環境・仲間・自信・透明性・自由度 など）
- `】` の直後に **半角スペース**を入れ、続けて **キャッチーな1行**（タイトル）
- タイトルは「〜できる」「〜が手に入る」「〜の約束」など、得られるものを言い切る

良い例:
- `◆ 【最大1年間】未経験から着実にプロへ導く「AI×対面」のハイブリッド研修`
- `◆ 【環境の約束】「学習のみ」に100％専念できる、徹底した環境作り`
- `◆ 【切磋琢磨】一人じゃないから挫けない「10名以上の同期」という存在`
- `◆ 【確かな自信】実践的な課題制作を通じ、プロとしてデビュー`

避ける例:
- `■アピールポイント1`（番号だけで意味が伝わらない）
- `◆ 育成体制について`（説明調・ベネフィットがない）

## 本文（◆ ブロックの中身）

- 見出しの **直下** に 2〜4 行の説明文
- 必要に応じて `・` の箇条書きで要素を列挙（3〜5 個）
- 専門用語は避け、語りかける文体
- 「あなた」「私たち」「会社」を主語に取り、関係性を作る
- 「〜です／〜ます」基本だが、要所では言い切りも可

## 文体・トーン

- **語りかけ調**：熱量を保ちつつ、押し付けがましくならない
- **安心感**：不安を受け止め、解消する方向で語る
- **数字で語る**：年間休日 125 日以上／単価開示 100％／賞与年 4 回 等、設定.md の数字をきちんと盛り込む
- **絵文字は使わない**
- 装飾記号は `◆` `・` `■` `_斜体_` `*太字*` を使ってよい

## Indeed の記法

- `*太字*` / `_斜体_` / `- 箇条書き` / 段落は空行で区切る
- 改行はテキストエリアの改行がそのまま反映される

## 項目別の使い分け

### AT 仕事内容（必須・30 字以上）

完全版を使う（オープニング → 共感 → ◆ ブロック 3〜5 → クロージング）。
仕事内容そのものに加え、会社の強み・育成体制・配属イメージ・キャリアパスまで含める。

### AU アピールポイント（必須）

◆ ブロック中心。3〜5 ブロックで、報酬・働き方・成長環境・福利厚生など別軸の魅力を立てる。
オープニングは 1 行程度、クロージングは省略可。

### AV 求める人材（任意）

**AV だけは `◆` ブロックを使わず、`■` 見出し＋`・` 箇条書きのテンプレート形式で書く**（AT/AU の ◆ ブロックとは別ルール。AV のみこちらが優先）。全社・全職種共通。ブロックには **①固定（そのまま記載）／②基本文＋追記可／③職種で可変** の 3 種類がある。

雛形（ブロック順は固定。右の注記が各ブロックの扱い）:

```
■未経験者、既卒・第二新卒、歓迎          ← ①固定（そのまま）

■その他必要な経験・資格                  ← ①固定（そのまま）
・学歴不問 / 未経験OK

■こんな方、大歓迎です！                  ← ③職種で可変
・手に職をつけたい方
・独学に限界を感じている方
・将来性のある業界にキャリアチェンジしたい方

■求める人物像                            ← ②基本文＋追記可
・主体性を持って自分の意見を発信できる方
・明るく働いてくれる方
・人とのコミュニケーションが好きな方
など

■大歓迎スキル                            ← ③職種で可変
・ITに関する知見がある方
・実務経験がある方（雇用形態は不問）

■こんな理由で入社しています！            ← ③職種で可変
・働きながら勉強できるなんて一石二鳥！
・将来は成長業界で、会社に縛られず在宅ワークがしたい！
・まずは業界で実績を作ることが最優先！
・しっかり稼ぎたい！

【9割以上の方が未経験スタート！】          ← ①固定（そのまま）
飲食・サービス・一般事務・公務員・店長・営業など様々な経歴の方が、未経験からスキルを身につけて活躍中！
```

ブロック別ルール:
- **①固定（そのまま記載・改変しない）**:
  - `■未経験者、既卒・第二新卒、歓迎`（見出しのみ。下に箇条書きは付けない）
  - `■その他必要な経験・資格` ＋ `・学歴不問 / 未経験OK`
  - `【9割以上の方が未経験スタート！】` ＋ 続く一文「飲食・サービス・一般事務・公務員・店長・営業など様々な経歴の方が、未経験からスキルを身につけて活躍中！」
- **②基本文＋追記可**: `■求める人物像` の 3 行（主体性／明るく／コミュニケーション）＋`など` を基本文として保持し、職種に応じて項目を**臨機応変に追記**してよい。
- **③職種で可変**: `■こんな方、大歓迎です！` `■大歓迎スキル` `■こんな理由で入社しています！` の中身は職種に合わせて臨機応変に変更する（例: セキュリティなら「論理的に考えるのが好きな方」等）。

書式:
- 見出しは `■`（**直後にスペースを入れない**）、箇条書きは `・`。ブロック間は空行 1 つ。
- `■その他必要な経験・資格` の `・学歴不問 / 未経験OK` は半角スラッシュの前後に半角スペースを入れる。
- `◆ 【キーワード】タイトル` 形式は AV では使わない。

- 適用外: B 列（Indeed の「会社名」フィールド）。xlsx の正式社名フィールドなので各社の正式表記（`株式会社Ｘｅｄｇｅ`／`株式会社UPBUILD`／`株式会社iRup`）を維持。
