# Indeed 一括アップロード

引数で指定された会社の最新 xlsx を Indeed の一括アップロード画面に投稿する。

## 使い方

```
/upload-indeed <会社名>
```

- `<会社名>` は `iRup` / `UPBUILD` / `Xedge` のいずれか
- 当日（YYYYMMDD）の `<会社>/<会社>_YYYYMMDD.xlsx` を優先。なければそのフォルダ内で最新の xlsx を使う。

## 事前条件

- プロジェクトルートに `.env` が存在し、以下が定義されていること。
  - `INDEED_EMAIL=<Indeed ログイン用メールアドレス>`
  - `INDEED_PASSWORD=<パスワード>`
- アップロード対象の `<会社>/<会社>_YYYYMMDD.xlsx` が存在すること。
- 会社切替アカウントが 1 つで 3 社（iRup / UPBUILD / Xedge）を保持していること。

## 手順

1. **引数チェック**
   - 引数が `iRup` / `UPBUILD` / `Xedge` のいずれでもなければエラー終了し、ユーザーに会社名の指定を依頼する。

2. **アップロードする xlsx を特定**
   - `<会社>/<会社>_YYYYMMDD.xlsx`（本日日付）を最優先で探す。
   - 無ければ、そのフォルダ内の最新の `<会社>_*.xlsx` を選ぶ。
   - どちらも無ければエラー終了。

3. **認証情報の読み込み**
   - `.env` から `INDEED_EMAIL` と `INDEED_PASSWORD` を読み込む。
   - 値が空ならエラー終了。

4. **ブラウザでログイン**
   - `https://secure.indeed.com/auth?continue=https%3A%2F%2Femployers.indeed.com%2Fbulkupload&hl=ja&co=JP&userType=employer` にアクセス。
   - 既にログイン済みなら次へ。未ログインならメール → パスワードの順に入力してログイン。
   - **2 段階認証は無し**の想定。万が一表示された場合はそこで停止してユーザーに通知する。

5. **会社を切り替える**
   - 画面右上の会社名表示エリア（現在のアクティブ会社が表示されている）をクリック。
   - ドロップダウンから `<会社名>` を選択する（社名の部分一致で OK。例: `iRup` なら「株式会社iRup」）。
   - 切替後、右上の表示が期待する社名になっているかを必ず確認する。違っていればエラー終了。

6. **一括アップロード画面へ移動**
   - `https://employers.indeed.com/bulkupload` にアクセス。

7. **ファイル添付 → 投稿**
   - ファイル選択欄にステップ 2 で特定した xlsx の絶対パスを指定。
   - 「一括投稿」ボタンをクリックする。
   - 完了画面 or エラー表示が出るまで待つ（最大 60 秒）。

8. **結果の記録**
   - 完了画面 / エラー画面 / 中間確認画面のスクリーンショットを `<会社>/upload_logs/YYYYMMDD-HHMM.png` に保存。
   - `<会社>/upload_logs/upload_log.md` に以下を追記：

     ```
     ## YYYY-MM-DD HH:MM
     - 会社: <会社名>
     - ファイル: <使った xlsx の相対パス>
     - 結果: 成功 / 失敗（理由）
     - スクリーンショット: <ファイル名>
     ```

9. **ユーザーへの報告**
   - 成功時: 「<会社> の <ファイル名>（N 行）を一括投稿しました」と報告。
   - 失敗時: 失敗箇所のスクリーンショットを示し、エラーメッセージをそのままチャットに引用して報告。次のアクション（手動確認 / 行修正後の再実行）を提示。

## 注意

- アップロード後の挙動（エラー行があるとどこで止まるか、確認画面が出るか）は初回実行で確認する。挙動が分かったらこの手順書に追記すること。
- `.env` は **絶対にコミットしない**。`.gitignore` で除外済み。
- 一度に複数社まとめてやりたい場合は `/upload-indeed iRup` → `/upload-indeed UPBUILD` → `/upload-indeed Xedge` と 3 回実行する。
