   `Target page, context or browser has been closed`。

   > `Browser is already in use for /Users/.../ms-playwright-mcp/mcp-chrome-b744ba4, use --isolated to run multiple instances of the same browser`
3. `browser_close` / `browser_snapshot` も同じロックエラーで実行不可。
4. 待機（8秒→30秒→45秒→計約2分）を挟んで複数回リトライしたが、ロックは解放されず。
5. 当該プロファイルはホスト側で使用中（別の Playwright インスタンスがロック保持）。
   本セッションのサンドボックスからはホストの Chrome プロセス／プロファイルに触れないため、
   ロックの解除・強制クローズができない。
