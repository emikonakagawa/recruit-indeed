# 非掲載求人分析 ― 実行エラー（2026-07-28 07:00 / 定期実行）

## 結果: ログイン不可のため全社（iRup / UPBUILD / Xedge）とも分析未実施

定期実行タスク `indeed-analyze-unlisted-weekly` を起動し、`analyze-unlisted` スキルの手順に従って
Indeed 採用企業ダッシュボード（employers.indeed.com）へアクセスしたが、**ログイン画面で停止**した。

## 詳細

1. `https://employers.indeed.com/jobs` にアクセス → 未ログインのため
   `secure.indeed.com/auth`（ログイン画面）へリダイレクト。
2. `.env` の `INDEED_EMAIL`（****@gmail.com）を入力し「続ける」を押下。
3. 次画面が **「おかえりなさい！ お使いのメールは Google によって安全に保護されています」** となり、
   選択肢は以下の2つのみ:
   - **「Googleで続ける」**（Google OAuth。アカウント選択・Google 側の認証が必要）
   - **「代わりにコードでログイン」**（メールに送られる確認コードの入力＝実質2段階認証）
4. **パスワード入力欄は表示されない**。このアカウントは Google 連携（SSO）で保護されており、
   `.env` の `INDEED_PASSWORD` を使うパスワードログインの導線が無い。
5. コードログインを選んでも、確認コードは `****@gmail.com` の受信箱に届くが、
   当該 Gmail は本セッションに連携されていないためコードを取得できない。

いずれの経路も**対話的な人手の認証**が必要で、スキル・ステップ1.3の
「2段階認証が出たら停止してユーザーに通知」および定期実行タスクの
「ログインが求められた場合や接続が無い場合は、その旨を報告して停止」に該当するため、
**自動では続行せず停止**した。

## 再実行のための対応（ユーザー操作が必要）

次のいずれかを行うと、以降の定期実行が通るようになる見込み:

- **ブラウザに Indeed のログインセッションを残す**: 一度手動で employers.indeed.com に
  Google ログインし、Playwright が使うブラウザプロファイルにセッション（Cookie）を保持させる。
  → 次回以降は未ログインリダイレクトが起きず、そのまま求人一覧へ進める。
- もしくは、**確認コードが届く Gmail（****@gmail.com）を本ワークスペースに連携**し、
  コードログインを自動化できるようにする。
- Google OAuth を無くしパスワードログインが可能な設定に変える（Indeed 側でパスワードを設定）なら、
  `.env` の `INDEED_PASSWORD` で自動ログインできる可能性がある。
